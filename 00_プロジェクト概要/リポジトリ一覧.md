# リポジトリ一覧

このプロジェクトのリポジトリの一覧。`/project-init` はこの表を読んで、親フォルダの下にリポジトリを clone する。リポジトリを追加・変更したら、この表を更新する。

各リポジトリに必要な言語・ツールは、この文書ではなく、それぞれのリポジトリの中で宣言する（版の指定ファイルと、`CLAUDE.md` の「開発環境の前提」の節）。

作成日：2026-10-28
版：v0.1

---

## Git の置き場所

GitHub

PR は GitHub で作る。PR の作成と確認には GitHub CLI（`gh`） を使う。

## リポジトリ

親フォルダ `plantlog/` の直下に、次のリポジトリを並べて clone する。

- 「手元のフォルダ」は、clone したときのフォルダ名。スキルはこの名前でリポジトリを探すので、必ず `plantlog_〜` の形にする
- 「clone 元」には、GitHub の画面に表示される clone 用の URL をそのまま書く。リモートのリポジトリ名は、手元のフォルダ名と違ってもよい（Azure DevOps では、プロジェクトがまとまりを表すので `document`、`backend` のように名付けることが多い）

| 手元のフォルダ | 役割 | clone 元 | 既定のブランチ |
|---|---|---|---|
| `plantlog_document` | ドキュメント | `git@github.com:shiki-tak1090/plantlog_document.git` | `develop` |

まだ作られていないリポジトリは、clone 元の欄を「未作成」とする。`/project-init` は未作成のリポジトリを飛ばす。

## アクセス権

リポジトリが非公開の場合は、GitHub でリポジトリへのアクセス権（GitHub ならリポジトリへの招待、Azure DevOps ならプロジェクトへの参加）がないと clone できない。依頼先は 山田さん。
